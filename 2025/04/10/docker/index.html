Docker命令

发表于2025-04-10|更新于2025-04-10|常用命令
|字数总计:627|阅读时长:2分钟|阅读量:

以下是常用的 Docker 命令及其简要说明：

1. 基本命令

命令 描述
docker version 查看 Docker 的版本信息。
docker info 查看 Docker 系统的详细信息。
docker images 查看所有已下载的镜像列表。
docker ps 查看当前运行的容器。
docker ps -a 查看所有容器（包括停止的）。
docker pull <image> 下载镜像到本地，例如：docker pull nginx。
docker run <image> 从镜像创建并启动一个容器。
docker stop <container_id> 停止正在运行的容器。
docker start <container_id> 启动已经停止的容器。
docker restart <container_id> 重启容器。
docker rm <container_id> 删除容器（停止的）。
docker rmi <image_id> 删除镜像（需确保没有容器使用该镜像）。

2. 镜像管理

命令 描述
docker build -t <name> . 使用 Dockerfile 构建镜像。
docker tag <image_id> <new_name> 给镜像打标签。
docker history <image_id> 查看镜像的历史记录。
docker inspect <image_id> 查看镜像详细信息。

3. 容器管理

命令 描述
docker exec -it <container_id> /bin/bash 进入运行中的容器。
docker logs <container_id> 查看容器日志。
docker cp <src> <container_id>:<dest> 拷贝文件到容器中。
docker cp <container_id>:<src> <dest> 从容器中拷贝文件到主机。
docker top <container_id> 查看容器内的进程。
docker stats 查看运行容器的资源使用情况（CPU、内存等）。

4. 网络管理

命令 描述
docker network ls 列出 Docker 网络。
docker network create <network_name> 创建一个自定义网络。
docker network inspect <network_name> 查看网络详细信息。
docker network connect <network_name> <container> 将容器连接到指定网络。
docker network disconnect <network_name> <container> 从网络中移除容器。

5. 数据卷管理

命令 描述
docker volume ls 查看所有数据卷。
docker volume create <volume_name> 创建一个数据卷。
docker volume inspect <volume_name> 查看数据卷详细信息。
docker volume rm <volume_name> 删除数据卷。

6. Docker Compose

命令 描述
docker-compose up 启动服务并创建容器。
docker-compose up -d 后台运行服务。
docker-compose down 停止并删除服务容器。
docker-compose ps 查看 Compose 管理的容器状态。

7. 清理无用资源

命令 描述
docker system prune 清理未使用的容器、网络和镜像。
docker container prune 清理所有已停止的容器。
docker volume prune 清理所有未使用的卷。
docker image prune 清理所有悬空镜像（未被任何容器使用）。
