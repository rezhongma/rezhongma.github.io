title：笔试题目总结

try-catch-finally 结构的执行流程 ：

  1. 执行 try 块：
    • 程序首先执行 try 块中的代码。
    • 如果 try 块中的代码没有抛出任何异常，则跳过 catch 块，直接执行 finally 块（如果存在的话）。
  2. 捕获异常：
    • 如果 try 块中的代码抛出了一个异常，并且该异常类型与某个 catch 块声明的异常类型匹配，则执行相应的 catch 块。
    • catch 块可以有多个，每个 catch 块可以捕获不同类型的异常。程序会从上到下检查 catch 块，直到找到一个匹配的异常类型。
  3. 执行 finally 块：
    • 无论 try 块中的代码是否抛出异常，finally 块（如果存在）总是会被执行。
    • finally 块通常用于执行必要的清理操作，如关闭文件流或释放资源。
  4. 返回值：
    • 如果 try 块中有 return 语句，程序会先执行 finally 块，然后再返回值。
    • 如果 catch 块中有 return 语句，程序同样会先执行 finally 块，然后再返回值。
    • 如果 finally 块中有 return 语句，那么 finally 块的返回值将覆盖 try 或 catch 块中的返回值
异常类型 运行时异常 (Runtime Exception) 非运行时异常 (Checked Exception)
继承关系 继承自 RuntimeException 继承自 Exception，但不包括 RuntimeException
处理要求 不要求处理 编译器要求处理
通常的原因 代码逻辑错误（如空指针、数组越界等） 外部环境错误（如文件不存在、数据库连接失败等）
常见场景 编程错误 I/O 操作、数据库连接、网络操作等
