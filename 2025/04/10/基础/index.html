对于Map这种数据结构而言，其底层可以简单的理解为是由一个个节点进行构成的的树，而Map.Entry<K, V>就是其每一个节点

对于Map.Entry<K, V>来说，其是Map内部实现的用来存放<key, value>键值对映射关系的内部类，该内部类中主要提供了<key, value>的获取，value的设置以及Key的比较方式：

方法 解释
K getKey() 返回 entry 中的 key
V getValue() 返回 entry 中的 value
V setValue(V value) 将键值对中的value替换为指定value

2.Map接口中常用API

  Map接口提供了一些基本的方法，用于操作键值对。以下是Map接口的主要方法 ：

方法 解释
V get(Object key) 返回 key 对应的 value
V getOrDefault(Object key, V defaultValue) 返回 key 对应的 value，key 不存在，返回默认值
V put(K key, V value) 设置 key 对应的 value
V remove(Object key) 删除 key 对应的映射关系
Set keySet() 返回所有 key 的不重复集合
Collection values() 返回所有 value 的可重复集合
Set<Map.Entry<K, V>> entrySet() 返回所有的 key-value 映射关系
boolean containsKey(Object key) 判断是否包含 key
boolean containsValue(Object value) 判断是否包含 value

流（stream）

filter

  • 通过 Lambda 表达式对流中的元素进行条件过滤。
  • 结果是一个新流，只包含满足条件的元素。

map

  • map 用于将流中的元素进行转换。
  • 结果是一个新流，元素类型可以转换成另一种类型。

distinct

  • 过滤掉流中重复的元素。

sorted

  • 按照自然顺序对流中的元素进行排序，或者提供一个比较器进行自定义排序。

limit

  • 返回流中的前 N 个元素。

skip

  • 跳过流中的前 N 个元素，返回剩余的元素。

collect

  • 通常配合 Collectors 工具类使用。

forEach

  • 对每个元素进行操作，常用来输出元素或者处理数据。

reduce

  • 可以对流中的元素进行累加、乘积、连接等操作。

anyMatch、allMatch 和 noneMatch：判断流中的元素是否满足某个条件。

  • anyMatch：只要有一个元素满足条件返回 true。
  • allMatch：只有所有元素都满足条件才返回 true。
  • noneMatch：只有没有元素满足条件才返回 true。

findFirst 和 findAny：返回流中的第一个元素或者任意元素。

  • findFirst：返回流中的第一个元素。
  • findAny：返回流中的任意一个元素，通常用于并行流。
  1. count：统计流中元素的个数。
